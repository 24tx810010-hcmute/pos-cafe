# Chỉ mục bàn giao task

Mỗi task mới áp dụng [quy trình](../README.md) có một file bàn giao theo [mẫu](../templates.md#ban-giao). Đây là chỉ mục liên kết; trạng thái chi tiết ở từng file và phải đối chiếu source khi tiếp tục. Không tạo một file trạng thái duy nhất ghi đè việc của nhiều task.

| Task | Bàn giao | Ghi chú |
| --- | --- | --- |
| Đóng gói quy trình AI, 2026-09-16 | [adopt-ai-task-workflow.md](adopt-ai-task-workflow.md) | Chỉ hướng dẫn, mẫu và hồ sơ quy trình; xem file để biết kết quả kiểm tra |

Các task cũ chưa được nhập vào chỉ mục này. Khi tiếp tục một task cũ, dùng proposal/tasks/biên bản hiện hành để lập bàn giao đúng trạng thái; không tự chuyển toàn bộ backlog hoặc đánh dấu hoàn tất chỉ từ tài liệu lịch sử.
